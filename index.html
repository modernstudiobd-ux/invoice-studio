    Import line items

    Import a CSV or Excel spreadsheet — its columns are matched to your current table columns (and common aliases) automatically.
    How to set up your CSV / Excel file ▸

    One line item per row, with a header row on top. Headers are matched by name, plus these aliases:

    • SKUItem code, Product code, Code
    • DescriptionName, Item, Product, Course name
    • QuantityQty, Net qty, Net quantity — defaults to 1
    • RateUnit price, Price, Unit rate — or Amount ÷ Quantity
    • AmountTotal, Line total

    Column order and extra columns don't matter. Accepted: .csv, .xlsx, .xls

    Help & Support

    A few things that aren't obvious at a glance:
    • Undo / RedoCtrl+Z / Ctrl+Shift+Z (or Ctrl+Y), or the buttons in the toolbar
    • Reorder or resize columnsDrag a column header to reorder it, or its right edge to resize
    • Column settingsClick the "⋮" on any column header — type, alignment, calculation role, hide or remove
    • Resize the Design panelDrag its left edge, or double-click to reset
    • Import line items"Import CSV" above the table — see its own "How to set up your file" guide
    • Install as an appWorks fully offline once installed — look for the install banner or your browser's install icon
