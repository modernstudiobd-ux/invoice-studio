How to set up your CSV / Excel file ▸

Put one line item per row, with a header row on top naming each column. The importer matches your headers against your current table columns by name — plus these common aliases, so close variations still match automatically:

  • SKU — also matches: Item code, Product code, Code
  • Description — also matches: Name, Item, Product, Course name
  • Quantity — also matches: Qty, Net qty, Net quantity
  • Rate — also matches: Unit price, Price, Unit rate
  • Amount — also matches: Total, Line total

Column order in the file doesn't matter — only the header names do. If a row has an Amount but no Rate, the rate is calculated for you (Amount ÷ Quantity). Missing Quantity defaults to 1. Any extra columns in the file that don't match are simply ignored.

Accepted formats: .csv, .xlsx, .xls
