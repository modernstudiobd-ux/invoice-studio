    Import line items

    Import a CSV or Excel spreadsheet — its columns are matched to your current table columns (and common aliases) automatically.
    How to set up your CSV / Excel file ▸

    Put one line item per row, with a header row on top naming each column. The importer matches your headers against your current table columns (editable directly on the invoice table above) by name — plus these common aliases, so close variations still match automatically:

    • SKU — also matches: Item code, Product code, Code
    • Description — also matches: Name, Item, Product, Course name
    • Quantity — also matches: Qty, Net qty, Net quantity
    • Rate — also matches: Unit price, Price, Unit rate
    • Amount — also matches: Total, Line total

    Column order in the file doesn't matter — only the header names do. If a row has an Amount but no Rate, the rate is calculated for you (Amount ÷ Quantity). Missing Quantity defaults to 1. Any extra columns in the file that don't match are simply ignored.

    Accepted formats: .csv, .xlsx, .xls

    Danger zone

    Table columns

    Add, remove, rename, reorder, resize, align or hide columns — one column can be assigned as Quantity, Rate, and Amount. Changes update the invoice table immediately. You can also drag a column header or its right edge directly on the table to reorder or resize it.
